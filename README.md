# sw_chat — чат с ИИ прямо в терминале

sw_chat — это программа для общения с искусственным интеллектом
(Claude, GPT, Grok, Gemini, DeepSeek и другими) прямо из терминала.
Работает как обычный чат: вы пишете вопрос — получаете ответ.

Главная особенность: ИИ может **выполнять команды в вашей системе**.
Например, попросите «посмотри, сколько места на диске», и ИИ пришлёт
команду, которую sw_chat предложит выполнить — а результат сразу вернётся
обратно в чат. По умолчанию каждая команда выполняется только с вашего
разрешения.

Работает через сервис [302.ai](https://302.ai) — один ключ даёт доступ
ко всем популярным моделям сразу.

---

## Что умеет

- Красивый вывод ответов: заголовки, таблицы, списки, код — всё аккуратно
  в терминале.
- Выполнение команд из ответов ИИ (с подтверждением).
- Многострочный ввод и удобное редактирование.
- История диалогов, несколько независимых сессий.
- Быстрая смена модели на лету.
- Показывает, сколько токенов потрачено и во сколько это примерно обошлось.
- Прерывание длинного ответа по Ctrl+C.
- Голосовой ввод и озвучка ответов (только на Android в Termux).
- Одиночный вопрос одной командой или через пайп.

## Установка

### Быстрый способ (одна команда)

    curl -fsSL https://raw.githubusercontent.com/swarik/Chat-Assist/main/install.sh | bash

Скрипт сам поставит всё необходимое, соберёт программу и положит её
в `~/.local/bin/sw_chat`.

После установки, если терминал не видит команду `sw_chat`, выполните:

    source ~/.bashrc

(или просто откройте новый терминал).

### Ручной способ (Ubuntu / Debian)

Если не хочется запускать скрипты из интернета:

    sudo apt-get install -y g++ libreadline-dev libcurl4-openssl-dev
    mkdir -p ~/.local/include/nlohmann
    curl -fsSL https://github.com/nlohmann/json/releases/download/v3.11.3/json.hpp \
         -o ~/.local/include/nlohmann/json.hpp
    curl -fsSL https://raw.githubusercontent.com/swarik/Chat-Assist/main/sw_chat.cpp > sw_chat.cpp
    g++ -std=c++17 -O2 -I~/.local/include -o sw_chat sw_chat.cpp -lreadline -lcurl -lpthread
    mkdir -p ~/.local/bin
    cp sw_chat ~/.local/bin/

### Android (Termux)

    pkg install -y clang readline libcurl make

и далее — как в быстром способе. Для голосовых команд дополнительно
установите приложение **Termux:API**.

## Первый запуск

### 1. Получите ключ

Зарегистрируйтесь на [302.ai](https://302.ai) и скопируйте API-ключ.

### 2. Сохраните ключ

    echo "ваш-ключ-сюда" > ~/.config/302_key
    chmod 600 ~/.config/302_key

Если папки `~/.config` ещё нет:

    mkdir -p ~/.config

Можно вместо файла использовать переменную окружения — но файл удобнее,
ключ сохранится между запусками.

### 3. Запустите

    sw_chat

Появится приглашение `❯`. Пишите вопрос и нажимайте Enter.

Попробуйте для начала:

    Привет! Что ты умеешь?

### 4. Первые полезные команды

Внутри чата введите `/help` — увидите список всех команд.
Самые нужные на старте:

| Команда       | Что делает                                  |
|---------------|---------------------------------------------|
| `/help`       | список всех команд                          |
| `/model`      | выбрать модель (откроется меню)             |
| `/clear`      | очистить историю                            |
| `/cost`       | сколько токенов потрачено и примерная цена  |
| `/exit`       | выйти из программы                          |

## Другие способы запуска

Задать один вопрос и сразу выйти:

    sw_chat "Сколько будет 2+2?"

Передать текст из другой программы (перенаправлением):

    echo "Объясни, что такое DNS" | sw_chat

Выполнить команды, которые предложит ИИ (по умолчанию в режиме пайпа
команды не выполняются):

    echo "Покажи свободное место на диске" | sw_chat --exec

Посмотреть, какие команды ИИ предложил бы выполнить, но ничего не запускать:

    sw_chat --dry-run "Покажи список файлов в домашней папке"

Узнать версию или получить справку:

    sw_chat --version
    sw_chat --help

## Как это выглядит на практике

1. Вы пишете: `Сколько сейчас свободно на диске?`
2. ИИ отвечает текстом и присылает блок с командой (например, `df -h`).
3. sw_chat показывает эту команду и спрашивает: выполнить? `[y/n]`
4. Вы нажимаете `y`.
5. Команда выполняется, а её результат уходит обратно к ИИ.
6. ИИ комментирует результат и, если нужно, задаёт уточняющие вопросы.

Так можно просить ИИ сделать довольно сложные вещи шаг за шагом
(до 7 шагов подряд без вашего вмешательства — каждый шаг вы подтверждаете
или заранее включаете автоматический режим).

## Многострочный ввод

Обычно вопрос вводится в одну строку. Если нужен многострочный текст:

- начали печатать — вы уже в многострочном режиме;
- **пустой Enter** — отправить всё, что набрали;
- **`.`** на отдельной строке — вставить пустую строку;
- **`//`** — тоже отправить (если нужно явно завершить ввод).

Во время длинного ответа:

- **Ctrl+C** — прервать ответ;
- **Ctrl+C** два раза подряд — выйти из программы;
- **Ctrl+D** — то же самое, что выход.

| Команда           | Что делает                   |

|----------------|--------------------------------------------------------------|

## ⚠️ Безопасность

sw_chat выполняет команды, которые предлагает ИИ. Это удобно, но
требует внимания.

- **По умолчанию** каждая команда требует вашего согласия (`y` / `n`).
  Это безопасный режим — оставляйте его включённым, пока не привыкнете.
- **`/autorun`** включает автоматическое выполнение. ИИ больше не
  спрашивает разрешения — команды выполняются сразу. Пользуйтесь, если
  понимаете, что делаете.
- **`/FIRE`** — самый рискованный режим. ИИ выполняет команды полностью
  молча: вы не видите ни саму команду, ни её результат. Включается только
  явным подтверждением (нужно ввести слово `yes`).
- Программа предупредит, если команда выглядит явно опасной (удаление
  системных файлов и т.п.), но **это не защита**, а лишь подсказка.
- Для работы с важными данными запускайте sw_chat в отдельном контейнере
  или от имени пользователя без доступа к ключам и почте.

## Где хранятся настройки

| Что                          | Где                                        |
|------------------------------|--------------------------------------------|
| API-ключ                     | `~/.config/302_key`                        |
| Все настройки                | `~/.config/sw_chat/config.json`            |
| История диалогов             | `~/.config/sw_chat/sessions/`              |
| Список моделей (кэш)         | `~/.config/sw_chat/models.json`            |
| Инструкция для ИИ            | `~/tmp/system_prompt.txt`                  |
| «Память» ассистента          | `~/tmp/memo.md`                            |
| Экспорт диалогов             | `~/tmp/dialog_export.md`                   |

Эти файлы создаются и обновляются автоматически. Правки через команды
внутри программы (`/model`, `/temp`, `/voice` и т.п.) сохраняются сразу
и не теряются при перезапуске.

## Что установить (зависимости)

- компилятор C++17 — `g++` или `clang++`;
- библиотека `readline` (для удобного ввода);
- библиотека `curl` (для обращения к API);
- заголовочный файл `nlohmann/json` — ставится автоматически скриптом.

На Ubuntu/Debian: `g++ libreadline-dev libcurl4-openssl-dev`.
На Fedora/RHEL: `gcc-c++ readline-devel libcurl-devel`.
На Arch: `gcc readline curl`.
На openSUSE: `gcc-c++ readline-devel libcurl-devel`.
На Termux: `clang readline libcurl make`.

## Частые вопросы

**Не работает `sw_chat` после установки — «команда не найдена».**
Выполните `source ~/.bashrc` или откройте новый терминал. Если не помогло,
проверьте, что `~/.local/bin` есть в переменной `PATH`:

    echo $PATH

**Ошибка про API-ключ.**
Проверьте, что файл `~/.config/302_key` существует и не пустой:

    ls -la ~/.config/302_key

**Ответы модели не приходят, ошибка 429 или 5xx.**
Скорее всего, превышен лимит или сервис перегружен. sw_chat сам повторит
запрос несколько раз и при необходимости переключится на запасную модель.

**Хочу использовать другой сервис вместо 302.ai.**
Команда `/apibase https://ваш-сервер` — подойдёт любой API, совместимый
с OpenAI (`/v1/chat/completions`).

**Как обновиться до свежей версии?**
В чате: `/update`. Программа скачает новую версию, соберёт её и перезапустится.
