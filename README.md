# sw_chat — чат с ИИ прямо в терминале

**Версия 1.4.85**

sw_chat — это разговор с искусственным интеллектом, который живёт в терминале.
Никаких браузеров и вкладок: вы пишете вопрос, модель отвечает — с таблицами,
списками и подсветкой кода.

Но главное не это. sw_chat умеет **выполнять команды**, которые предлагает ИИ.
Спросите «сколько места на диске» — модель пришлёт `df -h`, программа спросит
разрешение, выполнит и вернёт результат обратно в чат. Получается не переписка,
а работа.

Работает через [302.ai](https://302.ai): один ключ — и доступны Claude, GPT,
Grok, Gemini, DeepSeek и другие модели. Переключаться между ними можно на лету.

---

## Что умеет

- Аккуратный вывод: заголовки, таблицы, списки, цитаты, код — всё читаемо в терминале.
- Выполняет команды из ответов ИИ — с подтверждением или без (по вашему выбору).
- Многострочный ввод с удобным редактированием.
- История диалогов и несколько независимых сессий.
- Смена модели на лету, без перезапуска.
- Считает токены и примерную стоимость.
- Прерывает длинный ответ по Ctrl+C.
- Голосовой ввод и озвучка — на Android в Termux.
- Один вопрос одной командой или через пайп.

## Установка

### Быстрый способ

    curl -fsSL https://raw.githubusercontent.com/swarik/Chat-Assist/main/install.sh | bash

Скрипт проверит зависимости, соберёт программу и положит её в
`~/.local/bin/sw_chat`. Если чего-то не хватает и установить без пароля
нельзя — он честно скажет, что поставить вручную, и не станет ломаться
на полпути.

После установки, если команда `sw_chat` не находится:

    source ~/.bashrc

или просто откройте новый терминал.

### Готовые бинарники

Компилятор не нужен — скачайте сборку из
[Releases](https://github.com/swarik/Chat-Assist/releases/latest):

| Платформа              | Файл                     |
|------------------------|--------------------------|
| Linux x86_64           | `sw_chat-linux-x86_64`   |
| Linux arm64            | `sw_chat-linux-aarch64`  |
| macOS (Apple Silicon)  | `sw_chat-macos-arm64`    |
| Android / Termux arm64 | `sw_chat-termux-aarch64` |

Пример для Linux x86_64:

    mkdir -p ~/.local/bin ~/tmp
    curl -fL https://github.com/swarik/Chat-Assist/releases/latest/download/sw_chat-linux-x86_64 \
         -o ~/tmp/sw_chat-linux-x86_64
    chmod +x ~/tmp/sw_chat-linux-x86_64
    mv ~/tmp/sw_chat-linux-x86_64 ~/.local/bin/sw_chat
    sw_chat

Ссылка `releases/latest/download/…` всегда ведёт на свежий релиз. Рядом лежит
`SHA256SUMS` — при желании сверьте хеш:

    sha256sum ~/.local/bin/sw_chat

Бинарнику нужны `libreadline` и `libcurl` — обычно уже стоят. Если нет:

    sudo apt-get install -y libreadline8 libcurl4     # Debian / Ubuntu
    brew install readline curl                         # macOS
    pkg install readline libcurl                       # Termux

> Бинарники собираются из тегов. Если в `main` появились новые функции,
> а релиз ещё не вышел — собирайте из исходника или дождитесь тега.

### Ручной способ (Ubuntu / Debian)

Если не хочется запускать скрипты из интернета:

    sudo apt-get install -y g++ libreadline-dev libcurl4-openssl-dev
    mkdir -p ~/.local/include/nlohmann
    curl -fsSL https://github.com/nlohmann/json/releases/download/v3.11.3/json.hpp \
         -o ~/.local/include/nlohmann/json.hpp
    curl -fsSL https://raw.githubusercontent.com/swarik/Chat-Assist/main/sw_chat.cpp > sw_chat.cpp
    g++ -std=c++17 -O2 -I~/.local/include -o sw_chat sw_chat.cpp -lreadline -lcurl -lpthread
    mkdir -p ~/.local/bin
    cp sw_chat ~/.local/bin/

### Android (Termux)

    pkg install -y clang readline libcurl make

Дальше — как в быстром способе. Для голосовых команд поставьте
приложение **Termux:API**.

### Windows (через WSL2)

На Windows проще всего поставить **WSL2** — среда полностью совместима с
Linux, и все возможности sw_chat (включая FIRE) работают как есть:

    wsl --install -d Ubuntu

После установки Ubuntu откройте терминал WSL и поставьте sw_chat как обычно:

    curl -fsSL https://raw.githubusercontent.com/swarik/Chat-Assist/main/install.sh | bash

Проверить, что WSL второй версии:

    wsl --update
    wsl --set-default-version 2

Нативной сборки под Windows (`sw_chat.exe`) пока нет — если нужна, напишите
в [Issues](https://github.com/swarik/Chat-Assist/issues).

## Первый запуск

### 1. Получите ключ

Зарегистрируйтесь на [302.ai](https://302.ai) и скопируйте API-ключ.

### 2. Сохраните ключ

    mkdir -p ~/.config
    echo "ваш-ключ-сюда" > ~/.config/302_key
    chmod 600 ~/.config/302_key

Можно вместо файла использовать переменную окружения, но файл удобнее:
ключ переживёт перезапуск.

### 3. Запустите

    sw_chat

Появится приглашение `❯`. Пишите вопрос и нажимайте Enter.

Для начала попробуйте:

    Привет! Что ты умеешь?

### 4. Первые полезные команды

Внутри чата введите `/help` — увидите полный список. Самое нужное:

| Команда       | Что делает                                  |
|---------------|---------------------------------------------|
| `/help`       | список всех команд                          |
| `/model`      | выбрать модель (откроется меню)             |
| `/reasoning`  | глубина рассуждения текущей модели          |
| `/clear`      | очистить историю                            |
| `/cost`       | сколько токенов потрачено и примерная цена  |
| `/exit`       | выйти из программы                          |

## Другие способы запуска

Один вопрос — и сразу выход:

    sw_chat "Сколько будет 2+2?"

Текст из другой программы:

    echo "Объясни, что такое DNS" | sw_chat

Выполнить команды, которые предложит ИИ (в режиме пайпа по умолчанию
команды не выполняются):

    echo "Покажи свободное место на диске" | sw_chat --exec

Посмотреть, что ИИ предложил бы, но ничего не запускать:

    sw_chat --dry-run "Покажи список файлов в домашней папке"

Продолжить сохранённую сессию при старте:

    sw_chat --restore-session

Версия и справка:

    sw_chat --version
    sw_chat --help

## Как это выглядит на практике

1. Вы пишете: `Сколько сейчас свободно на диске?`
2. ИИ отвечает текстом и присылает блок с командой (например, `df -h`).
3. sw_chat показывает команду и спрашивает: выполнить? `[y/n]`
4. Вы нажимаете `y`.
5. Команда выполняется, результат уходит обратно к ИИ.
6. ИИ комментирует и, если нужно, задаёт уточняющие вопросы.

Так можно шаг за шагом делать довольно сложные вещи — до 7 шагов подряд,
каждый под вашим контролем (или без него, если включите автоматический режим).

## Многострочный ввод

Обычно вопрос вводится одной строкой. Если нужен многострочный текст:

- начали печатать — вы уже в многострочном режиме;
- **пустой Enter** — отправить всё, что набрали;
- **`.`** на отдельной строке — вставить пустую строку;
- **`//`** — тоже отправить (если нужно явно завершить ввод).

Во время длинного ответа:

- **Ctrl+C** — прервать ответ;
- **Ctrl+C** два раза подряд — выйти из программы;
- **Ctrl+D** — то же самое, что выход.

## Команды по группам

Самый полный список всегда доступен по `/help all`. Ниже — по категориям.

### Модели

| Команда            | Что делает                                        |
|--------------------|---------------------------------------------------|
| `/model`           | меню выбора модели                                |
| `/model 5`         | выбрать модель номер 5 из списка                  |
| `/model claude`    | выбрать по имени/подстроке                        |
| `/models`          | список всех доступных моделей                     |
| `/models claude`   | отфильтровать список по слову                     |
| `/temp 0.5`        | «температура» (0 — строго, 2 — хаотично)          |
| `/maxtokens 8000`  | максимальная длина ответа                         |
| `/reasoning high`  | глубина рассуждения: `auto`, `low`, `medium`, `high`, `xhigh`, `max` |
| `/think on\|off`   | показывать или скрывать «монолог» модели          |

Клиент сам подбирает совместимый формат запроса для разных маршрутов 302.ai:
Claude идёт через нативный Anthropic Messages API, несовместимые поля
(`temperature`, `reasoning_effort`, слишком большой `max_tokens`) исключаются,
а ответ `-10003` автоматически повторяется с консервативным payload. Команды
`/about` и `/context` показывают, что именно уходит в запрос.

Для DeepSeek работает отдельная ветка профиля: уровень `max` уходит в API
как `reasoning_effort`, если маршрут его поддерживает.

## ⚠️ Безопасность

sw_chat выполняет команды, которые предлагает ИИ. Это удобно, но требует
внимания.

- **По умолчанию** каждая команда требует согласия (`y` / `n`). Это
  безопасный режим — оставляйте его, пока не привыкнете.
- **`/autorun`** включает автоматическое выполнение. ИИ больше не спрашивает
  разрешения — команды выполняются сразу. Пользуйтесь, если понимаете,
  что делаете.
- **`/FIRE`** — самый рискованный режим. ИИ выполняет команды полностью
  молча: вы не видите ни команду, ни результат. Включается только явным
  подтверждением (нужно ввести слово `yes`).
- Программа предупредит, если команда выглядит явно опасной (удаление
  системных файлов и т.п.), но **это не защита**, а лишь подсказка.
- Для работы с важными данными запускайте sw_chat в отдельном контейнере
  или от имени пользователя без доступа к ключам и почте.

## Где хранятся настройки

| Что                          | Где                                        |
|------------------------------|--------------------------------------------|
| API-ключ                     | `~/.config/302_key`                        |
| Все настройки                | `~/.config/sw_chat/config.json`            |
| История диалогов             | `~/.config/sw_chat/sessions/`              |
| Список моделей (кэш)         | `~/.config/sw_chat/models.json`            |
| Инструкция для ИИ            | `~/tmp/system_prompt.txt`                  |
| «Память» ассистента          | `~/tmp/memo.md`                            |
| Экспорт диалогов             | `~/tmp/dialog_export.md`                   |
| Сырой JSON API (при `/debug`) | `~/tmp/api_raw.json`                      |

Эти файлы создаются и обновляются автоматически. Правки через команды
(`/model`, `/temp`, `/voice` и т.п.) сохраняются сразу и не теряются при
перезапуске.

## Что установить (зависимости)

- компилятор C++17 — `g++` или `clang++`;
- библиотека `readline` (удобный ввод);
- библиотека `curl` (обращение к API);
- заголовочный файл `nlohmann/json` — ставится автоматически.

На Ubuntu/Debian: `g++ libreadline-dev libcurl4-openssl-dev`.
На Fedora/RHEL: `gcc-c++ readline-devel libcurl-devel`.
На Arch: `gcc readline curl`.
На openSUSE: `gcc-c++ readline-devel libcurl-devel`.
На Termux: `clang readline libcurl make`.

## Частые вопросы

**Не работает `sw_chat` после установки — «команда не найдена».**
Выполните `source ~/.bashrc` или откройте новый терминал. Если не помогло,
проверьте, что `~/.local/bin` есть в `PATH`:

    echo $PATH

**Ошибка про API-ключ.**
Проверьте, что файл `~/.config/302_key` существует и не пустой:

    ls -la ~/.config/302_key

**Ответы не приходят, ошибка 429 или 5xx.**
Скорее всего, превышен лимит или сервис перегружен. sw_chat сам повторит
запрос несколько раз и при необходимости переключится на запасную модель.

**Хочу другой сервис вместо 302.ai.**
Команда `/apibase https://ваш-сервер` — подойдёт любой API, совместимый
с OpenAI (`/v1/chat/completions`).

**Как обновиться до свежей версии?**
В чате: `/update`. Программа скачает новую версию, соберёт её и перезапустится.

**Чем отличается `/think` от `/reasoning`?**
`/reasoning` задаёт глубину рассуждения (сколько модель думает), а `/think`
только показывает или скрывает уже полученный «монолог» модели.
