# sw_chat

**Простой чат с нейросетями прямо в терминале.**

Спрашиваете — получаете ответ. При необходимости программа может выполнить команды на вашем компьютере (только после вашего согласия).

| | |
|:--|:--|
| Версия | **1.0.39** |
| Для кого | Linux, работа в консоли |
| Сервис по умолчанию | [302.ai](https://302.ai) |
| Исходный код | [`sw_chat.cpp`](./sw_chat.cpp) |

---

## Зачем это нужно

Обычные чаты открываются в браузере. **sw_chat** работает в терминале:

- быстро и без лишнего интерфейса;
- удобно на слабых компьютерах и удалённых серверах;
- можно прикреплять файлы, вести несколько диалогов, считать расход токенов;
- по желанию — просить модель помочь с командами в системе (осторожно!).

---

## Что умеет

| Возможность | Простыми словами |
|:--|:--|
| Диалог с моделью | Как в ChatGPT, но в консоли |
| Красивый текст | Заголовки, списки, таблицы, блоки кода |
| Несколько моделей | Claude, GPT, DeepSeek, Grok и др. (зависит от ключа) |
| Файлы | «Посмотри этот файл и объясни» |
| История | Диалоги сохраняются между запусками |
| Несколько сессий | Разные темы в разных «чатах» |
| Команды из ответа | Модель предлагает — вы подтверждаете `y` / `n` |
| Обновление | Команда `/update` внутри программы |

> **Важно про безопасность**  
> Команды на компьютере **не запускаются сами**, пока вы не включите опасный режим `/autorun`.  
> По умолчанию программа всегда спросит: выполнить или нет.

## Быстрый старт

### 1. Установите

**Вариант А — одной командой** (если есть `install.sh` в репозитории):

```text
curl -fsSL https://raw.githubusercontent.com/swarik/Chat-Assist/main/install.sh | bash
```

**Вариант Б — вручную** (Ubuntu / Debian):

```text
sudo apt-get install -y g++ libreadline-dev libcurl4-openssl-dev

mkdir -p ~/.local/include/nlohmann
curl -fsSL https://raw.githubusercontent.com/nlohmann/json/develop/single_include/nlohmann/json.hpp \
  -o ~/.local/include/nlohmann/json.hpp

curl -fsSL https://raw.githubusercontent.com/swarik/Chat-Assist/main/sw_chat.cpp -o sw_chat.cpp

g++ -std=c++17 -Os -I"$HOME/.local/include" -o sw_chat sw_chat.cpp \
  -lreadline -lcurl -lpthread

cp sw_chat ~/.local/bin/
```

Если `~/.local/bin` нет в `PATH`, скопируйте так:

```text
cp sw_chat ~/sw_chat
chmod +x ~/sw_chat
```

### 2. Добавьте API-ключ

1. Зарегистрируйтесь на [302.ai](https://302.ai) и получите ключ.  
2. Сохраните его:

```text
mkdir -p ~/.config
echo "sk-ВАШ-КЛЮЧ" > ~/.config/302_key
chmod 600 ~/.config/302_key
```

Ключ — как пароль: **никому не показывайте** и не публикуйте в GitHub.

### 3. Запустите

```text
sw_chat
```

или, если бинарник лежит дома:

```text
~/sw_chat
```

Напишите вопрос и нажмите **Enter** (ещё раз Enter — отправить).  
Справка внутри программы: `/help`

## Как пользоваться

### Обычный разговор

```text
sw_chat
```

| Хотите… | Сделайте… |
|:--|:--|
| Отправить сообщение | Пустой **Enter** или строка `//` |
| Написать несколько строк | Просто пишите; пустая строка в тексте — символ `.` |
| Прервать долгий ответ | **Ctrl+C** |
| Выйти | `/exit` |

### Один вопрос без «чата»

```text
sw_chat "Что такое DNS простыми словами?"
```

### Передать текст из другой программы

```text
echo "Кратко объясни HTTP" | sw_chat
```

Если нужно ещё и **выполнять** команды из ответа модели:

```text
echo "Покажи свободное место на диске" | sw_chat --exec
```

## Главные команды

Введите их прямо в чате (начинаются с `/`).

### На каждый день

| Команда | Что делает |
|:--|:--|
| `/help` | Короткая шпаргалка |
| `/help all` | Полный список команд |
| `/model` | Выбрать нейросеть |
| `/models` | Список моделей |
| `/file путь` | Положить файл в разговор |
| `/clear` | Начать диалог с нуля |
| `/exit` | Выйти |

### Настройки

| Команда | Что делает |
|:--|:--|
| `/temp 0.7` | «Креативность» ответов (обычно 0–2) |
| `/maxtokens 4096` | Насколько длинным может быть ответ |
| `/apibase` | Адрес API (по умолчанию 302.ai) |
| `/compact` | Тихий режим — меньше подсказок на экране |
| `/about` | Версия и пути к настройкам |

### История и сессии

| Команда | Что делает |
|:--|:--|
| `/history on` | Запоминать диалог |
| `/history off` | Не сохранять |
| `/save` / `/load` | Сохранить / загрузить вручную |
| `/new работа` | Новый чат с именем |
| `/list` | Все сохранённые чаты |
| `/switch дом` | Переключиться на другой чат |
| `/search слово` | Найти в истории |
| `/export md` | Выгрузить диалог в файл |

### Деньги и расход

| Команда | Что делает |
|:--|:--|
| `/tokens` | Сколько токенов ушло |
| `/cost` | Примерная стоимость в $ |
| `/cost live` | То же, с попыткой обновить цены |
| `/balance` | Есть ли ключ, какой сервер, счётчики |

### Осторожно: команды на компьютере

| Команда | Что делает |
|:--|:--|
| (по умолчанию) | Спрашивает `y` — да, `n` — нет, `a` — да для всех блоков сразу |
| `/autorun` | **Опасно:** выполнять без спроса |
| `/nores` | Не показывать вывод команд на экране (в историю всё равно попадёт) |

## Модели

```text
/models
/models deepseek
/models p2
/models refresh
/model 3
/model deepseek-chat
```

- **фильтр** — часть имени, например `deepseek` или `gpt`;  
- **p2** — вторая страница списка (на слабых ПК список режется на части);  
- **refresh** — скачать свежий список с сервера.

---

## Если модель предлагает команду

Иногда в ответе есть блок кода «для терминала». Программа:

1. покажет команду;  
2. спросит, выполнять ли;  
3. при `y` запустит и покажет результат;  
4. отправит результат обратно модели (можно продолжить цепочку до 7 шагов).

В результат всегда добавляется код выхода, например `[exit: 0]` — «всё прошло нормально».

> Не подтверждайте команды, которых не понимаете  
> (особенно удаление файлов, смена паролей, установка пакетов «вслепую»).

## Где лежат настройки

| Файл / папка | Зачем |
|:--|:--|
| `~/.config/302_key` | Ваш секретный ключ |
| `~/.config/sw_chat/config.json` | Модель, температура, api_base и др. |
| `~/.config/sw_chat/sessions/` | Сохранённые диалоги |
| `~/tmp/system_prompt.txt` | Ваши правила для модели (необязательно) |

Свой «характер» ассистента можно задать так:

```text
nano ~/tmp/system_prompt.txt
```

Пример содержимого:

```text
Отвечай по-русски, коротко и по делу.
Если даёшь команды для терминала — объясняй, что они делают.
```

## Слабый компьютер

Программа рассчитана и на скромное железо (в т.ч. старый 32-bit Linux и ~200+ МБ RAM):

- собирайте с `-Os`;  
- не скармливайте гигантские файлы (`/file` ограничен ~200 КБ);  
- список моделей листайте страницами: `/models p2`;  
- не включайте `/autorun` «на всякий случай».

---

## Обновление

Внутри чата:

```text
/update
```

Программа скачает новую версию, покажет, что изменилось, и после вашего «да» пересоберёт себя.

## Частые вопросы

**Не запускается / не найден sw_chat**  
Запустите полным путём: `~/sw_chat` или добавьте `~/.local/bin` в `PATH`.

**Пишет, что нет ключа**  
Проверьте файл `~/.config/302_key` или переменную `302_API_KEY`.

**Ответ пустой или ошибка сети**  
Проверьте интернет, ключ и баланс на стороне 302.ai. Команда `/about` покажет базовые настройки.

**Слишком дорого / длинный диалог**  
`/clear` — обнулить переписку; `/cost` — посмотреть оценку; смените модель на более дешёвую через `/model`.

**Как сменить сервер API?**  
`/apibase https://api.302.ai` (нужен совместимый с OpenAI Chat Completions API).
